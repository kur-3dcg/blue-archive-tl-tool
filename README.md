# ブルアカ TL作成支援ツール

ブルーアーカイブの総力戦・大決戦などで、スキルを使うタイミングを記録・共有するためのタイムラインツールです。

## URL

https://kur-3dcg.github.io/blue-archive-tl-tool/

## 主な機能
- 編成（通常モード: 6人 / 制約解除決戦モード: 10人）
- ドラッグ&ドロップでスキルを使うタイミングを配置
- コスト自動計算（SS・EXバフ・固有2のバフ時間延長・重装甲/RW人数・ナギサ（水着）のオーバーコストに対応）
- 複数EXスキル対応（EX1/EX2タブ切替、EXごとのコスト設定）
- **落とし生徒**（生徒を落とすタイミングを設定すると、その時点からコスト回復力が減る）
- **ステージギミック**（加算 / 乗算 / 固定。コクマー・グレゴリオ・セト・ゲブラのプリセット付き）
- **開始時コスト**の設定
- ボスプリセット（ボスを選ぶだけで編成・時間・ギミック・攻撃パターンのコメントを一括設定）
- スキルキュー（スキル使用順バッジ・スキル順検証・ゲーム再現モード（β版））
- NSタイムライン（NSの発動タイミングとバフ時間を表示）
- コメント（キャラ依存の黄色吹き出し / フリーの緑バブル、重なると自動で段積み）・矢印接続
- テキストマーカー（M:SS形式でまとめて入力 → タイムラインに縦線で表示）
- セーブ・ロード（ボス別ページ + フリー4ページ）・JSONファイル保存/読込
- URL共有・TLテキスト出力/インポート・TL画像出力（透過 / 白背景 / 分割）
- etcアイコン（コピー・聖遺物などをEX対象に指定）
- 多言語対応（日本語 / English / 中文（简） / 中文（繁） / 한국어）

## 操作

| 操作 | 動作 |
|------|------|
| クリック | スキルを選択（選択ツールバーで細かく移動） |
| ダブルクリック | フリーコメント追加（TL上どこでも可） |
| 右クリック | メニュー（削除・バフ終了にチェーン・まとめて削除） |
| ドラッグ | 移動 |
| Shift+クリック | EX対象指定 |
| Ctrl+クリック | キャラ依存コメント追加 |
| Alt+クリック | 矢印接続 |
| 中クリック+ドラッグ | TLをつかんで移動 |
| Shift+ホイール / Ctrl+ホイール | TL横移動 |

## 使い方

### 1. 生徒を登録する
- 起動時は「編成中」モードです。空のスロットをクリックして生徒を選んでください
- 通常モードは STRIKER 4枠・SPECIAL 2枠（計6人）、制約解除決戦モードは STRIKER 6枠・SPECIAL 4枠（計10人）まで登録できます
- コスト回復力は、編成している人数で計算されます（空き枠は数えません）
- **固有4**（SPのみ）: チェックするとコスト上限が+0.5されます
- **固有2**（全スロット、デフォルトON）: 対象の生徒のバフ効果時間が×1.19されます（ゲームと同じく1F単位で切り捨て）。固有4のチェックも固有2以上として扱います
- **先行ディレイ**: スキルを使ってから効果が出るまでの秒数です。バフの開始と終了がその分だけ後ろにずれます。キャラデータに値がある生徒はその値が初期値で、それ以外は0です
- **複数EXスキル**: キサキ（水着）のように複数のEXを持つ生徒は、スロットの下にEX1/EX2タブが出ます。選んでいるEXでTLに配置され、コストもEXごとに設定できます
- **スロット入れ替え**: 「編成中」で顔アイコン左の ⠿ をドラッグして別のスロットにドロップすると、キャラ・設定・配置済みスキルをまとめて入れ替えます（ST↔ST / SP↔SP のみ）
- 重装甲・レッドウィンターの人数は編成から自動で判定されます

### 2. スキルをタイムラインに配置する
- 「TL作成中」ボタンでモードを切り替えます
- 生徒アイコンをドラッグして、タイムラインのレイヤーにドロップします
- 配置したスキルには、使用前の所持コストと時間が表示されます。コストが足りないときは赤、ナギサ（水着）のオーバーコストで使えるときは黄色で表示されます

### 3. スキルを編集する
- **移動**: ドラッグで時間方向・レイヤー間を移動
- **細かく移動**: クリックで選択すると出るツールバーで、1秒 / 0.1秒 / 1F ずつ前後に動かせます
- **右クリックメニュー**: 削除、バフ終了にチェーン（バフが切れる時間に同じスキルを続けて配置）、同レイヤーの全削除、同キャラEXの全削除
- **コスト手動調整**: +/- ボタンでスキルごとのコストを増減
- **EX対象指定**: Shift+クリックでメニューを開いて対象を選択（生徒・コピー・聖遺物など）
- **フリーコメント**: TL上をダブルクリックで緑のコメントを追加。アイコンの上でダブルクリックすると、そのスキルの時間に追加します
- **キャラ依存コメント**: アイコンを Ctrl+クリックで黄色の吹き出しを追加（吹き出しを右クリックで削除）
- **移動ロック**: 「🔓移動可能 / 🔒移動禁止」ボタンで、スキルをドラッグで動かせないようにできます（クリック系の操作はそのまま使えます）
- **MinMaxスナップ**: ONにすると、コストが足りない位置に置いたときはコストが溜まる時間へ、コストがMAXのまま置いたときはMAXになった時間へ自動で寄せます
- **TLクリア**: 編成やコスト設定は残したまま、TL上のスキル・コメント・矢印・ギミック・落とし生徒を消します（確認あり）

### 4. 落とし生徒を設定する
- 生徒を意図的に落としてスキル回しを早くする手段を再現できます
- 「落とし生徒」ボタン（ギミックの右）でパネルを開き、落とす生徒（ストライカー）を選んで、落ちる時間を入力して「追加」
- 落ちた時間から、その生徒の分のコスト回復力（700とSS）が減ります。チェリノ・カノエ・クルミのSSや、RW・重装甲の人数への影響も自動で外れます
- 設定した時間には「○○落とし」のフリーコメントが自動で入ります（落とし生徒を削除するとコメントも消えます）
- 落ちた生徒のスキルは、スキル順検証で赤く表示され、ゲーム再現モードの手札からも消えます

### 5. ステージギミックを設定する
- 「ギミック」ボタンでパネルを開きます
- プリセットを選ぶか、「カスタム」で自分で設定して「追加」します
  - **加算**: コスト回復力を増やします（効果時間あり）
  - **乗算**: コスト回復速度を％で増やします（効果時間あり）
  - **固定**: 指定した時間にコストをそのまま獲得します（効果時間なし）
- プリセット
  - **コクマー バリスタ**: +1000 × 残っているST数（22秒）
  - **グレゴリオ**: +300 × 残っている人数（1:00〜0:10まで10秒ごと）
  - **セトの憤怒グロッキー**: +500 × 残っている人数（0:34.333から23秒）
  - **ゲブラ 知性の根源**: 回復速度 +25%（常時）
  - **ゲブラ ラジエイター過負荷**: +500 × 残っている人数（発動時間・効果時間は手入力）
- 人数はその時点で残っている人数で自動計算します（落とし生徒も反映されます）
- 設定したギミックはコストグラフの上に橙色の帯で表示されます
- 時間は全角（３：３０など）でも入力できます。入力が正しくないときはパネルに理由が表示されます

### 6. ボスプリセットを使う
- 「ボスプリセット」ボタンでパネルを開き、ボスのアイコンをクリックします
- 確認で「OK」を押すと、編成・時間・ステージギミック・攻撃パターンのコメントがまとめて設定されます
- オレンジの ◆ が付いているボスがプリセットありです（グレーのボスは未対応）
- 対応済み: **セトの憤怒**（4:30・制約解除決戦・専用編成・グロッキー・攻撃パターン22コメント）、**ゲブラ**（4:00・知性の根源・ラジエイター過負荷）

### 7. フリーコメント・テキストマーカーを配置する
- **ダブルクリック**: TL上をダブルクリックすると、その位置に緑のコメントを追加
- **ドラッグ**: 「TL作成中」でコメントボタンをドラッグしてタイムラインにドロップ
  - ドラッグで移動、ダブルクリックで編集、右クリックで削除
  - 重なったコメントは上の段にずらして表示されます
- **テキスト入力**: 「テキスト」ボタンでパネルを開き、`3:30.00 テキスト` の形で1行に1つずつ入力
  - タイムラインにティール色の縦線とラベルで表示されます
  - ドラッグで追加したコメントもパネルに反映されます

### 8. タイムラインの設定（TL設定▼）
- **時間**: プリセット（3:00 / 4:00 / 4:30 / 5:00）か自由入力（M:SS形式、Enterで確定、最大10:00）
- **レイヤー**: 1〜4個
- **NS表示**: NSタイムラインの表示/非表示
- **目標**: M:SS形式で入力すると、タイムラインに赤い縦線を表示
- **開始時コスト**: 戦闘開始時に持っているコスト（デフォルト0、0.1刻み）
- **スナップ**: ツールバーのボタンで 0.1秒 / 1F（1/30秒、ゲーム内30fps基準）を切り替え
- **表示範囲の移動**: 左右の ◀▶ ボタン（30秒ずつ）、中クリック+ドラッグ、Shift/Ctrl+ホイール

### 9. スキルキュー
- **スキル使用順バッジ**: 「編成中」で、手札の枠数（通常3・制約解除決戦5）より多く生徒を登録すると、各スロットの左上に順番のバッジが出ます。クリックすると順番を選び直せます
- **スキル順検証**: 「スキル順」ボタンをONにすると、その時点で手札にないスキルを赤く表示します
- **ゲーム再現モード（β版）**: 「TL作成中」で「ゲーム再現（β版）」ボタンをONにすると、手札のスキルだけを A'/B'/C'... として表示します
  - タイムラインに緑の縦線（再生位置）が出ます。時間目盛りをクリック・ドラッグすると動かせて、手札はその時点の状態になります
  - 手札からスキルを配置すると、再生位置がそのスキルの直後まで自動で進みます
  - 再生位置より後のスキルは薄く表示されます
  - Z / X / C / V / B キーで手札を選んで、タイムラインをクリックして配置することもできます
  - まだ再現できていない例外（リオのコピー、即時使用できるスキル、ハナコ（水着）の再ドローなど）があります

### 10. NSタイムライン
- EXタイムラインの下に、NSを持つ生徒の行が表示されます（TL設定▼の「NS表示」で切り替え）
- 一定間隔で発動するNSは、発動位置とバフ時間が自動で表示されます。発動位置はドラッグで調整でき、それ以降の発動もまとめてずれます（Shift+クリックで「この発動以降をリセット」）
- 条件で発動するNSは、行をクリックして発動位置を手動で追加します（ドラッグで移動、右クリックで削除）

### 11. 矢印接続
- スキルアイコンを Alt+クリックしてから、別のスキルを Alt+クリックすると矢印でつながります
- 「矢印」ボタンをONにすると、普通のクリックでつなげられます
- 矢印を右クリックで削除

### 12. 共有・出力する
- **URL出力**: 共有用URLをクリップボードにコピーします（X などにそのまま貼れます）
- **TL出力**: TLをテキスト（時間 / コスト / EX / コメント）でクリップボードにコピーします。スプレッドシートにそのまま貼れます
- **テキストからインポート**: TL出力のテキストを貼り付けてTLを復元します（以前の形式も読めます）。コストは読み込んだ後に計算し直すので、コスト列の数字は使いません
- **画像出力**: 透過 / 白背景 / 分割（ZIP）のPNG画像で保存します
- **JSON保存 / JSONから読込**: TLをファイルで保存・読み込みします
- **インポート**: 共有URLかコードを貼り付けて復元します
- 共有コード・JSONには、編成・スキル配置・コメント・ギミック・落とし生徒・開始時コスト・キュー順・NSの調整など、TLの内容がすべて入ります（ゲーム再現モードの再生位置は入りません）

### 13. セーブ・ロード
- ページを再読み込みしても、編成とTLは自動で元に戻ります
- 「セーブ」で保存、「ロード」で読み込みます（ボス別ページ + フリー4ページ、1ページ30枠）

### 14. 言語切替
- ヘッダー右上の「Language」で表示言語を切り替えられます（日本語 / English / 中文（简） / 中文（繁） / 한국어）
- 生徒名も各言語で表示されます（グローバル版に未実装の生徒は日本語名）
- 日本語以外のときは、生徒検索も各言語の名前で検索できます
